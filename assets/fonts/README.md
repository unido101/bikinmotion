# Font

Semua font di folder ini berlisensi SIL Open Font License (OFL) dan boleh dipakai di video.

| Berkas | Keluarga |
|--------|----------|
| Poppins-Bold/Medium/Regular.ttf | Poppins |
| Anton-Regular.ttf | Anton |
| CrimsonText-Bold/SemiBold.ttf | Crimson Text |
| FiraSans-Black.ttf | Fira Sans |
| AnonymousPro-Bold.ttf | Anonymous Pro |
| ArchivoBlack-Regular.ttf | Archivo Black |

Teks lisensi Anton, Crimson Text, Fira Sans, Anonymous Pro, dan Archivo Black ada di `lisensi/`. Poppins juga berlisensi OFL (sumber: Google Fonts); jika kamu mendistribusikan repo ini, sertakan berkas lisensinya dari https://fonts.google.com/specimen/Poppins.
