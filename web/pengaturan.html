Cara mendapatkan kunci

  1. Buka aistudio.google.com dan masuk dengan akun Google-mu.
  2. Buat API key baru di bagian API keys.
  3. Salin kuncinya, tempel di kolom di atas, lalu simpan.

Bagaimana kunci diperlakukan

  • Disimpan terenkripsi, tidak pernah ditampilkan lagi (hanya 4 karakter terakhir).
  • Hanya dipakai server saat memproses videomu sendiri.
  • Bisa dihapus kapan saja. Menghapus kunci langsung menghentikan pemakaiannya.
  • Pada paket gratis Gemini, menurut ketentuan Google isi permintaan dapat dipakai untuk meningkatkan produk mereka. Cek ketentuan terbaru, dan jangan menulis data pribadi di naskah.
